# Android AirCommand

Galaxy のポップアップウィンドウ / S プレビュー風の **フローティング円形ツールパレット**（Android / Kotlin / Jetpack Compose / Material 3 Expressive・ダイナミックカラー対応）。

## ダウンロード
[Releases](https://github.com/orokichi/OrbitPalette/releases/latest) から最新の APK をインストール。
※ CI 署名のため、更新時は旧バージョンをアンインストールしてから入れてください。

## 機能
- **円形パレット**：丸いボタンを押したまま指をぐるっと回すと、指の方向のツールが濃い色でハイライト。離すと起動（タップで開いてタップ選択も可・長押しでボタン移動）
- **スクリーンショット**：撮影後サムネイル表示 → タップでライトエディター（ペン・マーカー・テキスト、色、元に戻す/やり直し）→ 保存
- **キャンバス**：手書きメモのポップアップ。ML Kit 手書き認識で電話番号・メール・URL・住所を検出すると下線表示、タップで電話 / Gmail / ブラウザ / マップ
- **タッチビュー**：画面をなぞるとルーペ表示（倍率 1.5〜6x、✕ で終了）
- **電卓**：ポップアップ電卓
- **ライトノート**：自動保存のテキストメモ（電話番号等はリンク化）
- **ポップアップウィンドウ**：タイトルバーで移動、右下でリサイズ、最小化・最大化・閉じる

## 権限
- 他のアプリの上に表示（必須）
- 通知
- 画面キャプチャ（スクリーンショット・タッチビュー使用時に毎回確認）

画像は `Pictures/OrbitPalette` に保存されます。
